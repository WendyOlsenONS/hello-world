# hello-world
Hello world is a training codebase for learning about Git and Github.
The Hello-world exercise is based at URL https://docs.github.com/en/get-started/using-github/hello-world
The git language helps with verbs and nouns.  Nouns like 'status' represent information flows or files.  Verbs like git or pull represent actions that we take on the flows of information, or on files.
